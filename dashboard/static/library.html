Patch a ROM

Romhacks come as a patch (.bps, .ups, .ips or .xdelta) for the original game. Pick the patch; Tallgrass saves the patched game next to the original. .bps and .ups patches find their original automatically; for .ips and .xdelta, choose it.

Game names in EmulationStation

EmulationStation lists games by file name. Tallgrass can give the games it recognises their proper name and a short description. Your play counts and any names you've set yourself are kept, and the original list is saved as gamelist.xml.bak-tallgrass.
